## 符号主义

符号主义（Symbolicism），也被称为“逻辑AI”或“传统AI”。    
智能的本质，就是符号的计算与处理。

### 专家系统

* 知识库
    * 最常用的一种知识表示方法是产生式规则（Production Rules），即一系列“IF-THEN”形式的条件语句。
* 推理机
    * 正向链
    * 反向链

缺点：许多知识是内隐的、直觉性的，很难被清晰地表达为“IF-THEN”规则。预先编译规则系统脆弱

### ELIZA 聊天机器人

它从不正面回答问题或提供信息，而是通过识别用户输入中的关键词，然后应用一套预设的转换规则，将用户的陈述转化为一个开放式的提问。

例如，当用户说“我为我的男朋友感到难过”时，ELIZA可能会识别出关键词“我为……感到难过”，并应用规则生成回应：“你为什么会为你的男朋友感到难过？”

* ELIZA的算法流程基于模式匹配（Pattern Matching）与文本替换（Text Substitution）
    * 关键词识别与排序
    * 分解规则
        * 重组规则
            * 代词转换

缺点：缺乏语义、无上下文

### 基于大规模数据的预训练 NLP

从特定任务到通用模型
![进阶梯](..\..\docs\images\2-figures\1757246501849-7.png)

核心要素：

* 预训练阶段  
  首先在一个包含互联网级别海量文本数据的通用语料库上，通过自监督学习（Self-supervised
  Learning）的方式训练一个超大规模的神经网络模型。这个阶段的目标不是完成任何特定任务，而是学习语言
  本身内在的规律、语法结构、事实知识以及上下文逻辑。 **最常见的目标是“预测下一个词”。**

* 微调  
  完成预训练后，这个模型就已经学习到了和数据集有关的丰富知识。之后，针对特定的下游任务，
  只需使用少量该任务的标注数据对模型进行微调，即可让模型适应对应任务。

当模型的规模（参数量、数据量、计算量）跨越某个阈值后，它们开始展现出未被直接训练的、预料之外的 **涌现能力**（Emergent
Abilities）

* 上下文学习（In-context Learning）
* 思维链（Chain-of-Thought）推理
